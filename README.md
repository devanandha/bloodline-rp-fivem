# Bloodline RP — FiveM Roleplay Server

> An independently built, deployed and operated FiveM roleplay server project.

Bloodline RP is a multiplayer roleplay server project that I independently developed and operated, covering server configuration, custom scripting, systems integration, database management, deployment, troubleshooting and community operations.

This repository documents the technical development of the project, the systems I implemented, the engineering challenges encountered, and the adoption of the platform by its community.

## Project Overview

Bloodline RP was developed as a practical software engineering project using the FiveM ecosystem.

The project involved:

- Server architecture and configuration
- Custom gameplay scripting
- Integration and modification of server resources
- Database configuration and management
- Multiplayer system integration
- Server deployment and hosting
- Debugging and performance troubleshooting
- Administration and operational tooling
- Community deployment and management
